\begin{abstract}
	This report documents the implementation of an xLSTM-based pipeline for symbolic music generation. The project uses MIDI files from the matched subset of the Lakh MIDI Dataset, enriched with LastFM-derived tag annotations, and constructs deterministic train/validation/test splits with explicit controls against metadata and content leakage. Music is represented as discrete event sequences using a MidiTok REMI configuration with REMI+-style extensions in the active experimental tokenizer, and xLSTM language models are trained autoregressively on fixed-length token chunks. The practical contribution of the project is a reproducible workflow covering dataset construction, preprocessing, tokenization, xLSTM training, hyperparameter exploration and model selection.
\end{abstract}
