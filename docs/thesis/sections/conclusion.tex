\section{Conclusion}

This report documents the current practical state of an xLSTM-based symbolic
music generation pipeline. The implemented repository covers dataset
construction, leakage-aware train/validation/test splitting, lightweight MIDI
preprocessing, REMI+-style tokenization, xLSTM training, checkpointing,
validation logging, hyperparameter sweeps, and generation-oriented evaluation
infrastructure.

The completed experiments show that the strongest current validation candidate
is the base xLSTM trained with tokenizer 14, with the batch-size-16 run giving
the best scalar validation loss and the batch-size-8 run remaining a close and
practical alternative. The medium xLSTM follow-up is useful as a diagnostic
result: it demonstrates that more capacity and longer training can overfit the
current subset under the selected schedule, so final-checkpoint selection would
be misleading.

The main conclusion is therefore methodological rather than final musical
judgment. The project has produced a reproducible path to shortlist xLSTM
checkpoints, but final claims about generation quality require held-out
generated-MIDI evaluation and qualitative inspection. The next thesis step is to
evaluate the shortlisted xLSTM checkpoints on the test split, compare them
against a matched Transformer baseline, and select the final model using both
token-level and generated-output evidence.
